   제목은 웜 아이보리, 설명은 차분한 회색, 단계와 강조는 레드로 정리
   색상 전환 대신 얇은 선과 여백으로 섹션 경계를 구분

18. V5.7 문의 선택창 개선
   프로젝트 유형과 예상 공사 규모의 브라우저 기본 목록을 전용 드롭다운으로 교체
   웜 블랙 패널, 넉넉한 좌우 여백, 얇은 구분선과 레드 선택 표시 적용
   마우스·터치뿐 아니라 방향키, Enter, Space, Esc, Home, End 조작 지원

19. V5.8 전체 디자인 시스템 강화

20. V5.8 페이지별 차별화
   홈은 원형 설계축, 대형 고스트 타이포, 강화된 수치 패널과 직선형 공정 애니메이션으로 구성
   ABOUT은 프레임 처리한 공간 이미지, 회전 기준도, 반응형 가치 목록으로 구성
   PROCESS는 카드 반복 없이 세로 공정 레일과 현장 기록 이미지로 구성
   PROJECT는 기존 3열 카드 갤러리를 유지하고 이미지 오버레이와 깊이감 있는 호버만 강화
   상세 페이지는 갤러리 번호·열기 표시·다음 프로젝트 프레임을 추가
   문의 페이지는 독립 브리프 패널, 포커스 라인과 전용 선택창을 하나의 인터페이스로 통일

21. V5.8 모션 및 안정성
   웜 블랙 섹션 배경에는 애니메이션을 적용하지 않음
   글·선·이미지·버튼만 완만한 곡선으로 나타나도록 조정
   움직임 줄이기 설정 및 터치 환경에서는 포인터·회전·복잡한 호버 효과를 자동 비활성화

22. V5.9 전 페이지 화면 검수
   PC 1363px와 모바일 390px에서 22개 HTML을 실제 렌더링해 겹침과 간격을 전수 확인
   제목과 본문 위로 침범하던 코너 프레임, 대형 고스트 문자, 좌표 장식과 포인터 효과 제거
   홈 철학 본문이 한 글자씩 떨어지던 폭 문제와 기준 섹션 영문 장식의 본문 간섭 수정
   PC 마지막 문의 제목을 의도한 두 줄로 고정하고 모바일의 단어 단위 줄바꿈 유지
   프로젝트 15개 카드 및 상세별 9장 이미지 표시, PC·모바일 확대창 중앙 정렬 확인
   문의 커스텀 선택창의 여백, 열림·닫힘과 모바일 표시 상태 확인
   섹션 배경은 계속 고정하고 콘텐츠 모션만 유지해 스크롤 중 배경이 덮이는 현상 방지

23. V5.10 데스크톱 포인터 복원
   V5.8의 얇은 레드 원형 마우스 포인터 효과를 PC 환경에 다시 적용
   링크·버튼·입력 요소 위에서는 원이 자연스럽게 커져 클릭 가능한 영역을 표시
   모바일·터치 기기와 움직임 줄이기 환경에서는 포인터 효과를 자동 비활성화
   포인터는 클릭을 가로채지 않으며 페이지 배치와 간격에는 영향을 주지 않음

24. V5.11 커스텀 포인터 완성
   PC에서는 브라우저 기본 화살표를 숨기고 레드 원형 포인터만 표시
   링크·버튼·입력 요소 위에서는 원이 부드럽게 확대되는 반응 유지
   스크립트가 작동한 뒤에만 기본 화살표를 숨겨 예외 상황에서도 조작 가능
   모바일·터치 기기와 움직임 줄이기 환경은 기기 기본 포인터 유지

25. V5.12 에디토리얼 타이포 복원
   홈 철학 섹션의 대형 TRUST 타이포와 원형 설계축 복원
   홈 수치 섹션의 YEARS / WORKS / ONE 배경 타이포 복원
   PROJECT·STANDARD·PROCESS·ABOUT의 고스트 타이포 대비 강화
   기준 섹션 STRUCTURE / DETAIL / PROCESS 크기를 확대하고 오른쪽 잘림 제거

26. V5.12 이미지·여백 장식 보정

   PC의 넓은 빈 공간에 얇은 붉은 궤도 원을 배치해 시각적 밀도 보강
   모바일에서는 붉은 궤도 원을 숨기고 사진 여백과 모서리만 축소해 겹침 방지

27. V5.13 프로젝트 상세 상호작용 보정
   9장 갤러리 확대창에서도 PC 레드 원형 포인터가 계속 표시되도록 수정
   확대창을 닫으면 포인터가 본문으로 자연스럽게 돌아오도록 처리
   다음 프로젝트 사진의 안쪽 여백 테두리를 제거하고 이미지 외곽에 맞춘 호버 라인으로 변경

28. V5.13 대형 원형 장식 재구성
   V5.12에서 추가한 작은 붉은 점과 동심원을 모두 제거

   홈 기준·ABOUT·PROCESS의 넓은 여백에만 큰 설계 원을 화면 밖으로 잘리게 배치
   모바일에서는 추가 대형 원을 숨겨 제목과 본문이 겹치지 않도록 처리

29. V5.14 타이포그래피 대비 및 깊이감

   주요 제목에는 밝은 윗면과 짙은 아래 그림자를 미세하게 분리해 입체감 적용
   배경 타이포는 본문보다 뒤에 유지하고 모바일에서는 큰 장식을 줄여 겹침 방지

30. V5.15 호버 정렬 및 연결감 보정
   ABOUT 세 가지 기준의 빨간 영문 라벨을 호버 면에서 안쪽으로 띄워 여백 확보
   기준 행의 왼쪽에 얇은 레드 시작선을 적용해 여백이 의도된 구조로 보이도록 정리
   PROCESS 호버 색면을 타임라인 축에서 시작해 행 전체로 부드럽게 사라지는 면으로 변경
   공정 노드에 은은한 레드 빛을 더해 선·번호·본문이 하나의 동작으로 연결되도록 보정

31. V5.16 홈 기준 섹션 왼쪽 여백 보정
   01·02·03 번호와 STRUCTURE·DETAIL·PROCESS 라벨에 동일한 안쪽 여백 적용
   제목·설명·대형 외곽선 타이포 위치는 유지해 기존 편집 그리드 보존
   호버 전후의 라벨 위치를 고정해 마우스를 올릴 때 생기던 답답함과 흔들림 제거

32. V5.17 모바일 전 페이지 안정화
   홈·ABOUT·PROCESS·PROJECT·문의·완료 화면과 프로젝트 상세 15개를 360~390px 기준으로 전수 점검
   홈 STANDARD 항목을 모바일 한 열 구조로 바꿔 영문 인덱스와 제목·설명의 충돌 제거
   모바일 히어로 제목, 긴 영문 프로젝트명, 하단 YISO® 워드마크와 버튼 폭을 화면 안에 맞게 보정

   문의 입력 글자를 16px로 맞춰 iOS 자동 확대를 방지하고 드롭다운이 화면 아래에서 잘릴 때 위로 열리도록 처리
   긴 파일명·메일·메타데이터 줄바꿈과 터치 환경의 잔류 호버 이동 효과 정리

33. V5.18 콘셉트 프로젝트 투명성 표기
   프로젝트 목록 15개와 홈 대표 프로젝트 3개의 이미지에 CONCEPT 배지 적용
   상세페이지 15개의 첫 화면과 다음 프로젝트 미리보기에도 같은 배지를 일관되게 적용
   각 상세페이지 하단에 개별 프로젝트 고지문을, 프로젝트 목록 하단에 전체 목록용 고지문을 작은 크기로 명시
   프로젝트 링크의 보조기기용 설명에도 콘셉트 디자인임을 반영
