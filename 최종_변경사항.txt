YISO INTERIOR 최종 수정본

1. 시작 파일

2. 헤더 구조
   왼쪽 상단: YISO 로고 (HOME 이동, 등록상표 기호 없음)
   가운데: ABOUT / PROCESS / PROJECT
   오른쪽: PROJECT INQUIRY

3. 강조 표현
   ABOUT / PROCESS / PROJECT 페이지의 첫 화면은 홈과 같은 흰색 외곽선 글자
   본문 강조 범위는 원래 문장 단위로 복원
   배경 박스와 기울임, 별도 서체를 제거하고 동일 폰트의 YISO 레드 글자색 적용
   글자 아래에 2~3px의 얇은 레드 라인을 더해 선명하게 강조

4. 프로젝트 구성
   프로젝트 15개
   프로젝트별 상세 이미지 9장
   전체 이미지 135장

5. 문의 페이지
   PROJECT INQUIRY에서 contact.html로 이동
   기존 프로젝트 문의 폼과 첨부 기능 유지

6. PROJECT 목록
   이미지·번호·분야·프로젝트명·설명을 하나로 묶은 카드형 갤러리
   PC 3열 / 태블릿 2열 / 모바일 1열로 반응형 배치

7. 카카오톡 공유
   images/kakaotalk-preview.png 파일과 OG 메타태그 연결

8. 반응형 및 모션
   모바일 헤더를 두 줄 구조로 정리해 겹침 방지
   주요 버튼의 한글 단어 단위 줄바꿈 방지
   화면 크기에 맞춰 제목 크기 조정
   섹션 배경은 처음부터 고정해 배경색이 번쩍이거나 덮이는 현상 제거
   글·숫자·카드 등 내부 콘텐츠만 완만하게 나타나는 애니메이션 적용

9. 화면 정리
   VIEW ALL SPACES / 15 버튼을 문의 버튼과 같은 색·호버 방식으로 변경
   ABOUT·PROCESS 하단 CTA 배경을 화면 전체 너비로 확장
   PROJECT 소개 문구를 "공간의 규모를 넘어, 완성의 기준을 설계합니다."로 수정

10. V5.1 보정
   프로젝트 목록이 애니메이션 표시 조건 때문에 숨는 현상 수정
   PC 주요 제목 크기를 15~25% 축소
   모바일 글자 크기는 기존 설정 유지
   왼쪽 하단 YISO® 워드마크의 등록상표 기호 복원
   PC·모바일 한글 줄바꿈 규칙 재검사

11. V5.2 보정
   전체 모션 지속시간과 가속 곡선을 더 부드럽게 조정
   홈 대표 프로젝트 3개를 동일한 카드 규격의 3열 갤러리로 변경
   전체 프로젝트 15개를 동일한 카드 규격의 3열 갤러리로 변경
   태블릿 2열, 모바일 1열 전환 적용

12. V5.3 보정
   PC 마우스 휠에 부드러운 관성 스크롤 적용
   모바일과 터치 기기는 기기 고유의 자연스러운 스크롤 유지
   문의 입력칸, 확대 이미지, 내부 스크롤 영역은 관성 효과에서 제외
   움직임 줄이기 설정을 사용하는 환경에서는 효과를 자동 비활성화

13. V5.4 섹션 그래픽
   철학 섹션의 여백에 공간의 구조와 신뢰를 표현한 다이어그램 추가
   STRUCTURE / DETAIL / PROCESS를 각각 중첩 프레임, 교차선, 연결선으로 시각화
   홈과 ABOUT의 세 가지 기준을 이미지형 그래픽 카드로 재구성
   홈 HOW WE WORK와 PROCESS 상세 단계에 공정 흐름을 표현한 그래픽 추가
   섹션 배경은 고정하고 내부 선과 접점만 부드럽게 나타나도록 설정

14. V5.4 숫자 모션
   홈과 ABOUT의 07 / 110+ / 01에 자릿수 롤링 효과 적용
   화면에 들어왔을 때 한 번만 실행하고 최종 숫자 및 앞자리 0을 정확히 유지
   움직임 줄이기 설정에서는 애니메이션 없이 최종 숫자를 즉시 표시

15. V5.5 섹션별 재설계
   반복되던 카드형 추상 그래픽과 검은 패널을 모두 제거
   홈 철학은 대형 TRUST 타이포와 세로 기준선으로 구성
   홈의 세 가지 기준은 폭이 달라지는 편집형 가로 띠로 구성
   홈 과정은 네 단계가 하나의 붉은 동선으로 이어지는 구조로 구성
   ABOUT의 세 가지 기준은 하나의 3축 기준도와 설명 목록으로 통합
   PROCESS 상세는 카드가 아닌 연속 세로 진행선과 단계별 정보 구조로 변경

16. V5.5 숫자 모션
   무작위 숫자 변화와 마지막 튕김 효과 제거
   0부터 실제 값까지 순서대로 증가하는 단방향 카운터 적용
   07 / 110+ / 01의 앞자리 0과 최종 표기를 정확히 유지

17. V5.6 배경 및 홈 프로세스 정리
   홈 HOW WE WORK의 계단형 동선을 제거하고 최초 버전의 직선형 4단계 타임라인으로 복원
   사진이 들어간 히어로·프로젝트 이동 구간을 제외한 모든 본문 섹션을 웜 블랙으로 통일
   제목은 웜 아이보리, 설명은 차분한 회색, 단계와 강조는 레드로 정리
   색상 전환 대신 얇은 선과 여백으로 섹션 경계를 구분

18. V5.7 문의 선택창 개선
   프로젝트 유형과 예상 공사 규모의 브라우저 기본 목록을 전용 드롭다운으로 교체
   웜 블랙 패널, 넉넉한 좌우 여백, 얇은 구분선과 레드 선택 표시 적용
   마우스·터치뿐 아니라 방향키, Enter, Space, Esc, Home, End 조작 지원
   기존 선택 항목과 FormSubmit 전송값은 변경 없이 유지
