YISO INTERIOR 최종 수정본

1. 시작 파일
   index.html

2. 헤더 구조
   왼쪽 상단: YISO 로고 (HOME 이동, 등록상표 기호 없음)
   가운데: ABOUT / PROCESS / PROJECT
   오른쪽: PROJECT INQUIRY

3. 강조 표현
   ABOUT / PROCESS / PROJECT 페이지의 첫 화면은 홈과 같은 흰색 외곽선 글자
   본문 강조 범위는 원래 문장 단위로 복원
   배경 박스와 기울임, 별도 서체를 제거하고 동일 폰트의 YISO 레드 글자색 적용
   글자 아래에 2~3px의 얇은 레드 라인을 더해 선명하게 강조

4. 프로젝트 구성
   프로젝트 15개
   프로젝트별 상세 이미지 9장
   전체 이미지 135장

5. 문의 페이지
   PROJECT INQUIRY에서 contact.html로 이동
   기존 프로젝트 문의 폼과 첨부 기능 유지

6. PROJECT 목록
   이미지·번호·분야·프로젝트명·설명을 하나로 묶은 카드형 갤러리
   PC 3열 / 태블릿 2열 / 모바일 1열로 반응형 배치

7. 카카오톡 공유
   images/kakaotalk-preview.png 파일과 OG 메타태그 연결

8. 반응형 및 모션
   모바일 헤더를 두 줄 구조로 정리해 겹침 방지
   주요 버튼의 한글 단어 단위 줄바꿈 방지
   화면 크기에 맞춰 제목 크기 조정
   섹션 배경은 처음부터 고정해 배경색이 번쩍이거나 덮이는 현상 제거
   글·숫자·카드 등 내부 콘텐츠만 완만하게 나타나는 애니메이션 적용

9. 화면 정리
   VIEW ALL SPACES / 15 버튼을 문의 버튼과 같은 색·호버 방식으로 변경
   ABOUT·PROCESS 하단 CTA 배경을 화면 전체 너비로 확장
   PROJECT 소개 문구를 "공간의 규모를 넘어, 완성의 기준을 설계합니다."로 수정

10. V5.1 보정
   프로젝트 목록이 애니메이션 표시 조건 때문에 숨는 현상 수정
   PC 주요 제목 크기를 15~25% 축소
   모바일 글자 크기는 기존 설정 유지
   왼쪽 하단 YISO® 워드마크의 등록상표 기호 복원
   PC·모바일 한글 줄바꿈 규칙 재검사

11. V5.2 보정
   전체 모션 지속시간과 가속 곡선을 더 부드럽게 조정
   홈 대표 프로젝트 3개를 동일한 카드 규격의 3열 갤러리로 변경
   전체 프로젝트 15개를 동일한 카드 규격의 3열 갤러리로 변경
   태블릿 2열, 모바일 1열 전환 적용

12. V5.3 보정
   PC 마우스 휠에 부드러운 관성 스크롤 적용
   모바일과 터치 기기는 기기 고유의 자연스러운 스크롤 유지
   문의 입력칸, 확대 이미지, 내부 스크롤 영역은 관성 효과에서 제외
   움직임 줄이기 설정을 사용하는 환경에서는 효과를 자동 비활성화
