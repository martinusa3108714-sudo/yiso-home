YISO INTERIOR 최종 수정본
수정일: 2026-09-04

1. 시작 파일
   index.html

2. 헤더 구조
   왼쪽: YISO® 로고 (HOME 이동)
   가운데: ABOUT / PROCESS / PROJECT
   오른쪽: PROJECT INQUIRY

3. 강조 표현
   ABOUT / PROCESS / PROJECT 페이지의 첫 화면은 홈과 같은 흰색 외곽선 글자
   본문 강조 범위는 원래 문장 단위로 복원
   배경 박스와 기울임, 별도 서체를 제거하고 동일 폰트의 YISO 레드 글자색 적용
   글자 아래에 2~3px의 얇은 레드 라인을 더해 선명하게 강조

4. 프로젝트 구성
   프로젝트 15개
   프로젝트별 상세 이미지 9장
   전체 이미지 135장

5. 문의 페이지
   PROJECT INQUIRY에서 contact.html로 이동
   기존 프로젝트 문의 폼과 첨부 기능 유지

6. PROJECT 목록
   직전 변경 전의 기존 비대칭 프로젝트 배치로 복원
