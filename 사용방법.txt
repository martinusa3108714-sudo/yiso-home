YISO INTERIOR 홈페이지 HTML 시안

1. 압축을 해제합니다.
2. 폴더 안의 index.html 파일을 더블클릭합니다.
3. Chrome, Edge 등 웹 브라우저에서 홈페이지를 확인할 수 있습니다.
4. 왼쪽 상단 YISO 로고는 HOME, 가운데 ABOUT / PROCESS / PROJECT 메뉴는 각 독립 페이지로 이동합니다.
5. 왼쪽 하단의 큰 YISO® 워드마크에는 등록상표 기호가 유지됩니다.
6. 15개 프로젝트의 사진 또는 제목을 누르면 각 프로젝트 상세 페이지로 이동하며, 프로젝트마다 9장의 개별 이미지가 열립니다.
7. 우측 PROJECT INQUIRY 또는 프로젝트 문의하기를 누르면 contact.html 문의 페이지로 이동합니다.
8. 프로젝트 목록은 PC 3열, 태블릿 2열, 모바일 1열 카드형 갤러리로 자동 전환됩니다.
9. PC에서는 마우스 휠을 움직일 때 부드러운 관성 스크롤이 적용되며, 모바일은 기본 터치 스크롤을 사용합니다.
10. 홈과 ABOUT의 07 / 110+ / 01은 처음 화면에 들어올 때 0부터 실제 값까지 한 방향으로 증가합니다.
11. 철학·기준·프로세스의 타이포그래피와 선 요소는 별도 이미지 파일이 아니라 HTML과 CSS에 포함되어 있어 추가 업로드가 필요하지 않습니다.
12. 사진 히어로를 제외한 모든 본문 섹션은 동일한 웜 블랙 배경으로 이어지며, 홈 HOW WE WORK는 얇은 가로선의 4단계 구성입니다.
13. 문의 페이지의 프로젝트 유형과 예상 공사 규모는 사이트 전용 선택창으로 열리며, 마우스·터치와 키보드 방향키로 선택할 수 있습니다.
14. 스크롤 진행선, 글라스 헤더, 미세 질감과 카드 반응은 site-motion.js와 global.css에 포함되어 있어 별도 플러그인이 필요하지 않습니다.
15. 배경은 전 페이지에서 같은 웜 블랙으로 고정되며 애니메이션은 내부 콘텐츠에만 적용됩니다.
16. V5.9는 PC 1363px·모바일 390px 기준으로 22개 HTML을 다시 확인해, 장식과 문구의 겹침·비정상 줄바꿈·가로 넘침을 정리한 검수본입니다.
17. PC 마우스 환경에서는 기본 화살표 대신 얇은 레드 원형 포인터만 표시되며, 링크·버튼 위에서 자연스럽게 커집니다. 모바일·터치 기기는 기존 방식 그대로 작동합니다.
18. TRUST / YEARS / WORKS / ONE 등 큰 외곽선 타이포와 대형 설계 원은 CSS 장식이며, 본문보다 뒤에 배치되고 모바일에서는 겹침 방지를 위해 일부 장식이 자동으로 숨겨집니다.
19. ABOUT 대표 사진은 PC에서 양옆 여백과 둥근 모서리를 사용하며, 모바일에서는 화면 폭에 맞춰 여백과 곡률이 자동으로 줄어듭니다.
20. 프로젝트 갤러리 확대창에서도 PC의 레드 원형 포인터가 유지되며, 다음 프로젝트 호버 테두리는 사진 외곽선에 밀착해 표시됩니다.
21. V5.14에서는 TRUST를 기준으로 큰 외곽선 타이포의 농도를 맞추고, 제목·설명문에 미세한 명암과 그림자를 더해 웜 블랙 배경의 가독성을 높였습니다.
22. V5.15에서는 ABOUT의 기준 라벨 여백과 PROCESS의 호버 연결 범위를 조정해 마우스를 올렸을 때 색면과 글이 자연스럽게 이어집니다.
23. V5.16에서는 홈 기준 섹션의 01·02·03 번호와 영문 라벨을 행의 왼쪽 가장자리에서 안쪽으로 띄워 호버 색면 안에서도 일정한 여백을 유지합니다.
24. V5.17에서는 360~390px 모바일 폭을 기준으로 전체 22개 페이지의 제목·본문·버튼·폼·갤러리 구조를 다시 점검했습니다. 홈 기준 항목은 한 열로 정리되고, 프로젝트 확대창의 하단 조작부와 문의 선택창은 작은 화면에서도 서로 겹치거나 잘리지 않도록 자동 배치됩니다.
25. V5.18에서는 홈페이지와 프로젝트 목록·상세페이지에 CONCEPT 배지를 표시합니다. 각 상세페이지 및 프로젝트 목록 하단의 영문 고지문은 해당 이미지와 프로젝트가 YISO의 공간 디자인 방향을 탐구하기 위한 콘셉트 스터디임을 안내합니다.

주의: assets, images 폴더와 HTML, CSS, JS 파일은 현재 폴더 구조 그대로 두어야 디자인과 이미지가 정상적으로 표시됩니다.
