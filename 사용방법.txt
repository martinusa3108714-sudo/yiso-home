YISO INTERIOR 홈페이지 HTML 시안

1. 압축을 해제합니다.
2. 폴더 안의 index.html 파일을 더블클릭합니다.
3. Chrome, Edge 등 웹 브라우저에서 홈페이지를 확인할 수 있습니다.
4. 왼쪽 YISO® 로고는 HOME, 가운데 ABOUT / PROCESS / PROJECT 메뉴는 각 독립 페이지로 이동합니다.
5. 15개 프로젝트의 사진 또는 제목을 누르면 각 프로젝트 상세 페이지로 이동하며, 프로젝트마다 9장의 개별 이미지가 열립니다.
6. 우측 PROJECT INQUIRY 또는 프로젝트 문의하기를 누르면 contact.html 문의 페이지로 이동합니다.

주의: assets, images 폴더와 HTML, CSS, JS 파일은 현재 폴더 구조 그대로 두어야 디자인과 이미지가 정상적으로 표시됩니다.

포트폴리오 전체 페이지
- spaces.html

회사 소개 페이지
- about.html

진행 과정 페이지
- process.html

프로젝트 상세 페이지
- project-로 시작하는 HTML 파일 15개

프로젝트 문의 페이지
- contact.html
- inquiry.html은 기존 링크 호환용으로 동일하게 유지됩니다.

배포 전 확인
- 현재 프로젝트 명칭과 이미지는 홈페이지 시안 구성을 위한 콘텐츠입니다.
- 실제 회사 포트폴리오로 공개할 때는 수행 사실과 사용 권한이 확인된 프로젝트 명칭·설명·사진으로 교체하세요.
- FormSubmit 문의 전송은 index.html을 더블클릭한 file:// 환경에서는 작동하지 않습니다. 실제 웹주소 또는 로컬 웹서버에서 테스트하세요.
